      AI assistant

      Ask in plain language: a coding agent reads your data, runs tools and publishes results to a notebook.

      On this page5
      1. Ask a question
      2. Ask about what you see
      3. Read the results
      4. Let it change the view
      5. Keep your notebooks

      The Assistant needs one AI runtime, installed and signed in as described in Installation.

      Ask a question

      1. Press Assistant at the bottom right.

        Or press Cmd/Ctrl + J.

      2. Choose the runtime, model and thinking effort.

        Press the pill with the runtime’s name under the field; the choice is fixed after the first question.

      3. Choose Auto or Ask.

        Auto runs the agent’s commands without asking; Ask holds each command that changes something until you press Allow.

      4. Type a question and press Enter.

        Name cell types, genes and sections as the dataset labels them.

      Caution

      The agent runs the code it writes on the computer that serves PointillViz, with your permissions, and what it reads goes to the runtime’s provider. On a shared or sensitive machine, choose Ask.

      Ask about what you see

      The view

      Each question carries the open dataset, the active tab and what colours the cells, so “the gene I am looking at” needs no name. Press @ before sending to add a picture of the view.

      A selection

      Select cells first, for example with the lasso (see 2D data). While the selection stands, its cells go with every question, so “my selection” means exactly those cells.

      Read the results

      Method

      Under each question, every step the agent ran: the tabs’ own statistics, tools from the Tool Store or Python scripts of its own.

      R01, R02 …

      Every figure, table or note the agent publishes gets a number. Derivation, under a result, shows the script that made it; Readouts, at the top, shows the results alone.

      Linked to Cell View

      On an interactive result, hover a bar, square or point to light up its cells in the tissue, and click to pin them. Clicking a gene’s point paints that gene.

      Let it change the view

      By default the agent only looks. Set Viewer control, at the top of the panel, to Ask or Allow to let it move the camera, switch tabs, colour the cells, show sections and select cells. With Ask, each change waits for Allow or Deny; a new notebook starts at Off.

      Paint its own values

      Asked how far each cell type lies from the labyrinth, the agent wrote a script for it. It painted each cell’s distance on the tissue and drew the distances per cell type.

      Move the camera

      Asked to run the Expression Hotspots tool for one gene and zoom onto the strongest patch, the agent painted the tool’s score. A second Allow let it move the camera there.

      Keep your notebooks

      Export

      Saves the notebook as one web page with every figure and script, to keep or print to PDF. Interactive figures work only inside PointillViz.

      Notebooks

      Lists your notebooks, newest first. Open one, and your next question continues it.

      New notebook

      Starts an empty notebook; the current one stays under Notebooks.
