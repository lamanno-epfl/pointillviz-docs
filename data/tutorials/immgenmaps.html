Install PointillViz

Keep the folder's two parts side by side: PointillViz is the app, dist its installers.

Mac app

  1. Open dist/PointillViz-Installer.dmg and double-click Install PointillViz.

    A Terminal window shows each step; the first time takes 5 to 15 minutes.

  2. Open PointillViz from Applications.

    It starts PointillViz in your browser and stays in the Dock while it runs.

The first double-click is blocked

The installer is not signed: in System Settings › Privacy & Security, press Open Anyway, then double-click it again.

Terminal

Follow Installation, but skip git clone: you already have the folder.

On Linux, bash dist/install.sh instead installs everything and adds PointillViz to the applications menu.

Open the colon as an atlas

  1. Press Upload, then Multiple sections (Atlas view).

  2. Open the folder with the colon .h5ad, click the file, press Scan.

    Clicked, only that file is read, split into its four sections by Sections from: sample_id. With none clicked, each .h5ad of the folder would be one section.

Space is X_spatial; IFQUANT, X_pca and X_scVI are Matrices; the UMAPs are Embeddings, shared by the four sections.

Cell types by Subtype, under Class and Type

  1. Set Cell types to Subtype.

  2. Under Cell Type Hierarchy, tick Class and Type.

  3. Keep Split by Type.

    'Unspecified' and 'Unresolved' are Subtypes of several Types: each gets one per Type, such as 'Unspecified - enteric glial cell'. Drop these cells leaves them out instead.

Import and explore

  1. Press Import atlas, then Open.

  2. Pick sections in the strip at the bottom: Multi, All or Single.

    The Types tab holds Class › Type › Subtype as a tree.
