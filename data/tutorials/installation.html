What you need

  • git, to clone PointillViz.
  • curl or wget, on macOS and Linux. The commands below use curl; with wget, replace curl -fsSL with wget -qO-.
  • For ChatGPT Codex only: Node.js 18 or newer, with npm. The Node.js of Ubuntu 22.04’s apt (12) is too old.

Install pixi

PointillViz installs with pixi, which brings Python and every package PointillViz uses, at the versions pixi.lock pins. Install it once, then open a new terminal. On Windows, use PowerShell.

Install PointillViz

pixi install builds PointillViz’s environment, exactly as pixi.lock pins it.

Run PointillViz

The viewer opens on http://localhost:8090; pixi run serve 8095 serves it on another port. It listens on this computer only: on a remote machine, forward the port (VS Code, ssh -L) and open it in your own browser.

To stop it, press the power button in the top-left corner of any page, or Ctrl + C in its terminal.

Without pixi

./serve.sh runs the server on whichever python3 is on your PATH: Python 3.10 or newer, with numpy. PYTHON=/path/to/python ./serve.sh 8090 pins one.

Choose a runtime for the Assistant

The Assistant is the button at the bottom right of every page, or Cmd/Ctrl + J. It needs one AI runtime, installed on your computer apart from PointillViz and signed in once with your own account; PointillViz never sees your password or token. Install one of the three, and restart PointillViz afterwards if it is running.

Claude Code

  1. Install Claude Code

  2. Add claude-agent-sdk

    The library PointillViz drives Claude Code through. Run this inside PointillViz/: it records the library in the clone’s pixi.toml and pixi.lock, so git shows both as changed.

  3. Sign in once

    Open the Assistant and press Sign in to Claude Code: your browser opens the sign-in page. If that page asks you to paste a code, run this in any terminal instead.

ChatGPT Codex

  1. Install ChatGPT Codex

    It needs Node.js 18 or newer, with npm.

  2. Sign in once

    Open the Assistant and press Sign in to ChatGPT Codex: your browser opens the sign-in page. Or run this in any terminal, with --device-auth on a remote machine.

Google Antigravity CLI (preview)

  1. Install the Antigravity CLI

  2. Sign in once

    Start agy in a terminal and follow its prompts, or open the Assistant and press Sign in to Google Antigravity. PointillViz cannot ask this runtime whether you are signed in, so the panel works either way; press I’m signed in to dismiss the card.

Add your data

Open the viewer, press Upload, and drop in the file: the import wizard maps its fields onto the viewer and converts it in the background. See Importing.
