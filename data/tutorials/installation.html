What you need

  • git, to clone PointillViz.
  • curl, on macOS and Linux. Ubuntu 22.04 can come without it: sudo apt install curl.
  • For ChatGPT Codex only: Node.js 18 or newer, with npm. The Node.js of Ubuntu 22.04’s apt (12) is too old.

Install pixi

PointillViz installs with pixi, which brings Python and every package PointillViz uses, at the versions pixi.lock pins. Install it once, then open a new terminal. On Windows, use PowerShell.

Install PointillViz

pixi install builds PointillViz’s environment, exactly as pixi.lock pins it.

Run PointillViz

Without the Assistant

The viewer opens on http://localhost:8090; pixi run serve 8095 serves it on another port. It listens on every network interface, so other machines on your network can reach it.

With the Assistant

Then press Assistant, or Cmd/Ctrl + J. With the Assistant on, the server listens on 127.0.0.1 only. It needs a runtime: choose one below.

Without pixi

./serve.sh runs the server on whichever python3 is on your PATH: Python 3.10 or newer, with numpy. PYTHON=/path/to/python ./serve.sh 8090 pins one.

Choose a runtime for the Assistant

The Assistant needs one AI runtime, installed on your computer apart from PointillViz and signed in once with your own account. Install one of the three before you start the Assistant.

Claude Code

  1. Install Claude Code

  2. Add claude-agent-sdk

    The library PointillViz drives Claude Code through. Run this inside PointillViz/: it records the library in the clone’s pixi.toml and pixi.lock, so git shows both as changed.

  3. Sign in once

ChatGPT Codex

  1. Install ChatGPT Codex

    It needs Node.js 18 or newer, with npm.

  2. Sign in once

Google Antigravity CLI (preview)

  1. Install the Antigravity CLI

  2. Sign in once

    Start agy and follow its prompts.

Add your data

Open the viewer, press Upload an .h5ad or + Add, and drop in the file: the import wizard maps its fields onto the viewer and converts it in the background. See Importing.
