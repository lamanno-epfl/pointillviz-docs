Pick a gene set

  1. Open the Pathways tab and choose a source.

  2. Search, then click a set.

    In Hallmark and Mine, a gene name finds the sets that hold it.

  3. Check its genes.

    Plain chips are measured, struck-through ones are not, and an arrow gives the name a gene is measured under.

Hallmark

The 50 MSigDB Hallmark sets, built in and grouped by process. Customize on a set’s card opens a copy to edit in Mine.

Reactome

Searched online: type a pathway name or its ID (R-HSA-…). Reactome’s pathways are human, so for mouse data each gene becomes its mouse orthologs. Save to My Pathways keeps the list for use offline.

GO

Searched online: type a biological process or its ID (GO:…). Curated annotations only, on by default, leaves out genes annotated by computer prediction. Save to My Pathways keeps the list.

Mine

Press New pathway, name it, type or paste its genes and press Save pathway. Your sets are kept in this browser, for this dataset.

Score it on the tissue

  1. Press Score.

    The set’s genes fill the Quick score box: edit them, or paste any gene list, before scoring.

  2. Read the colours.

    Orange cells express the set more than control genes of similar expression; blue cells, less.

  3. Hover a cell for its score.

  4. Set the Colour scale.

    Auto stretches each map to its own range; ±1 gives every map the same range, so sets compare.

How the score works

Scanpy’s score_genes on log-normalized counts: the set’s mean expression minus that of control genes drawn at the same expression levels. A set with few measured genes gives a noisy score.

Compare sets in the gallery

  1. Press Open Pathway Gallery.

    Every Hallmark set and each of your own sets appears as a small scored map.

  2. Search by name, or choose a Category under Filters.

  3. Click a map to score its set on the tissue.
