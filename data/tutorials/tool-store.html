The Tool Store is where PointillViz gets analyses that other people wrote. A tool is a small program, in Python or R, that reads the open dataset, asks for its parameters in a form, and returns a value per cell, a chart, a heatmap, a table or a figure. Installed tools sit in the Tools tab beside the built-in analyses and run on the computer that serves PointillViz.

The store exists twice: as a website, store.pointillviz.com, where every tool has a page with its readme, its test report and its source, and inside the viewer, where the same list installs with one click. Both read the public registry, and anyone can publish a tool there.

A tool is code

An installed tool runs with the permissions of whoever started PointillViz: it can read and change whatever they can, like any script downloaded from the internet. The store's checks report what a tool reaches for; they cannot stop it. There are no ratings or reviews in the store: the test report and the source are what there is to judge a tool by. Read the source before installing. Every tool's page links to it.

Get, use and publish tools

Five things can be done with a tool: find it on the store website, add it to the viewer, build one of your own, run it on the open dataset, and manage the tools you have. Choose one; the rest of this page follows it.

Find a tool

This step explains how to search the catalogue, review a tool’s details and tests, and prepare it for installation. At the end, the tool is either listed in PointillViz under Tools → Community Tools → Tool Store with an Install button, or available as a downloaded .pvtool file. It is not installed yet; continue with Add a tool before running it.

  1. Open the store website

    Go to store.pointillviz.com. Every published tool is a card with its picture and its name.

  2. Find a tool

    Search. Type a word into Search tools (or press /): a word of the name, the description or the author. The cards narrow as you type, and the count beside Filters says how many match. Esc clears the field.

    Filter. Press Filters. Tags narrows by topic (spatial, cell types, expression, niches…), Outputs by what a tool returns (cells for a map, matrix for a heatmap, series for a chart, images for figures…), each with the number of tools it would leave. One tag and one output can be chosen at a time; pressing a choice again clears it. Sort orders by newest or A–Z. A pill under the field names the active filter; clicking it removes the filter.

  3. Open the tool's page

    Click a card; the example opens store.pointillviz.com/tools/local-density. The head of the page shows the summary and the Download button; the side column names the author, version, publication date, licence, language, GPU use and what a dataset must have (here 50+ cells). Readme explains the method; Parameters lists every setting with its default and range; Outputs says what comes back.

  4. Check its tests

    Press Tool test summary in the tab bar. A panel lists the nine checks the tool passed when this version was released, each with one line on what it found; imports says what the code reaches for. Close it with × or Esc. Source in the public registry opens the code itself.

  5. Download the file

    Press Download. The browser saves one file, here local-density-2.0.0.pvtool (21 kB), to its download folder. Nothing is installed yet.

  6. Switch back from the store website to PointillViz

    The viewer runs on your computer and normally opens at http://localhost:8090 (see Installation). The website cannot install a tool into the viewer directly: either select the downloaded .pvtool through Install from file, or install it from the store list in the Tools tab.

  7. Install from file

    In PointillViz, open the Tools tab, scroll to Community Tools and press Install from file, at the right of the Installed title. Choose the downloaded file in the file dialog.

  8. Choose where it goes

    The install dialog opens, named after the file and marked From a file. Keep Own environment (recommended) and press Install. The second choice, PointillViz's environment, is explained under Add a tool.

  9. Wait for the checks

    Four stages follow: Unpack, Environment, Checks, Done. The checks run the tool once on a small test dataset, on the CPU. At the end the dialog reads Installed Local Cell Density v2.0.0 into its own environment and lists what the tool imports. Press Close.

  10. Find it under Installed

    The tool's card now sits under Installed, with its picture, author and version. Opening and running it is described under Run a tool.

Add a tool

Start with a tool prepared through Find a tool. Install it from the Tool Store list or through Install from file. Tools are installed on the computer that runs PointillViz and need pixi (see Installation).

  1. Open the Tools tab

    In the viewer, open the Tools tab and scroll to Community Tools at the end of the gallery. Installed comes first; the Tool Store follows below it.

  2. Look through the Tool Store

    The Tool Store lists what the store offers and is not installed yet. The green dot says the list is live; the ↻ button reads the store again. Each card shows the tool's picture, its name and one row of tags: the language (Python or R), GPU when the tool can use one, and what it returns. Search tools at the top of the tab finds store tools as well as installed ones.

    A tool announced but not yet published is shown dimmed as Coming soon and cannot be installed.

  3. Read about it first

    Rest the pointer on a card for its one-sentence description. ↗ at the right of Install opens the tool's page on the store website, with its readme, its test report and its source; see Find a tool for how to read it.

  4. Press Install

    Press Install on the card.

  5. Choose where it goes

    A dialog names the tool, its version and language, and asks where its packages should go. Both choices need pixi.

    Own environment (recommended) builds the tool a separate environment inside its own folder, exactly as its author pinned it; nothing PointillViz uses can change.

    PointillViz's environment adds the tool's packages to the environment PointillViz runs in, which takes less disk space. It is offered only when PointillViz was started with pixi run serve; otherwise it is greyed, with the reason. If the packages would change one PointillViz already has, a warning lists the changes first, with Install anyway and Use own environment; if they cannot be combined at all, only Use own environment remains.

    Press Install in the dialog to start.

  6. Watch the install

    Four stages run: Download, Environment, Checks, Done. The checks run the tool once on a small test dataset; a tool that fails one is refused, and a version already installed stays as it was. At the end the dialog shows a Validation report with what the tool touches; press Close. Closing the dialog earlier does not stop the install.

  7. Find it under Installed

    The tool's card moves up to Installed and leaves the store list. It shows the author, the version, what the tool shows and what it draws (map, chart, heatmap, table…). A tool the open dataset cannot support is shown disabled, with the reason in place of its picture (for instance needs cell-type annotation, which this dataset does not have), not hidden. Opening and running it is described under Run a tool.

Build & share a tool

Eight steps from an idea to a tool in the store. No programming is needed to start: the registry is public and its author guide is written so that an AI assistant can build the tool from it.

  1. Start with an idea

    What should the tool answer, and what should come back: a value painted on every cell, a chart, a heatmap, a table or a figure? One clear question is enough, for example how crowded is the tissue around each cell. Note which inputs it needs: coordinates, genes, cell types, an annotation.

  2. Open the author guide

    On the store website, open Build & publish a tool and press Read the author guide. The guide is a page in the public registry on GitHub; it says everything a tool must contain.

  3. Let an assistant write it

    The easiest way is to let an AI assistant such as Claude or ChatGPT Codex write the tool. On the guide's page, the copy button beside Raw copies the whole guide; paste it into the assistant together with your idea, and say whether you want Python or R.

    The registry is public, so the assistant can also read the tools that already exist, under tools/, as examples. With the guide and your idea it writes every file the tool needs, in the right format: the manifest, the code, the readme and the environment.

  4. Check it

    The guide comes with a checker that runs the same nine tests as the store. Ask the assistant to run it, or run it yourself in the tool's folder:

    It must end with PASSED. If a test fails, the report names it and says why; give that text back to the assistant and let it fix the tool.

  5. Try it in PointillViz

    python -m pointillviz_tool pack my-tool writes a .pvtool file. Install it with Install from file (see Find a tool, step 7) and run it on a real dataset (see Run a tool). Change what does not feel right and check again.

  6. Publish it

    On GitHub, press Fork on the registry, add your tool's folder under tools/ in your copy, and open a pull request. The assistant can do these steps too; it only needs your GitHub account.

  7. Wait for the checks

    The registry runs the nine tests again, in the tool's own environment, and looks for private paths or addresses in the files. When they pass, the pull request is merged on its own; nobody has to review it. When something fails, a comment under the pull request says what, and you can push a fix.

  8. Find it in the store

    After the merge the tool is released. It appears in the viewer's Tool Store within minutes and on the website within the hour, with its readme as its page and its test report beside it. You are its owner: only you can publish a newer version, and every change needs a higher version number.

Run a tool

Eight steps, with Local Cell Density as the example: how crowded the tissue is around every cell. Every tool runs the same way: a form, Run, and the result underneath.

  1. Open the tool

    In the Tools tab, click the tool's card under Installed. Its details open at the right.

    Press Open, or click the card again. The tool's panel opens over the tissue.

  2. Set the parameters

    Each setting has a ? that explains it. Here Neighbours (k) is set to 20; Scale stays at log10 density. The line above Run says which cells the tool will see: every cell, or only those selected with the Lasso.

  3. Run it

    Press Run. While the tool works, the button reads Running…; Cancel stops it.

  4. Read the result

    The status reads Done in 2.2 s. A value per cell comes with a colour bar, its range and its unit.

    Below it, the tool's chart: the density of every cell, from the sparsest to the most crowded.

  5. Paint the map

    Press Paint the map. The tissue takes the tool's colours: crowded regions yellow, sparse ones dark. Cells without a value stay dim.

  6. Read a cell

    Rest the pointer on a cell. Its tooltip now ends with the tool's value.

  7. Read the tool's summary

    ⓘ in the panel's head opens About this tool: what it does, its author and version, and, under This run, the tool's own summary of the result.

  8. Keep or close it

    A result stays in the panel until the next run, another tool or another dataset; nothing is saved. To keep it, capture the painted view, or export it with Export data as Community tool result (see Exporting). × closes the panel and takes the colours off the tissue; › minimizes it to the rail at the right edge.

Other tools, other results

Tools differ in what they return. A heatmap or chart reads its values on hover; a table sorts by a click on a column; a figure opens at full size with a click; files appear under Downloads. A tool that can use a graphics card shows a CPU / GPU switch. Some tools can sweep one setting over a range: Run sweep under that setting, then a slider steps through the results.

Manage your tools

Installed tools work without the store. It is needed only to find newer versions.

Update

A gold Update on a card means the store has a newer version; hover it to see both. Press it: the install dialog runs the checks again, and the old version stays until the new one passes.

A tool that cannot open

A tool that cannot run here is greyed, with the reason in place of its picture: the dataset lacks what it needs, or, as here, the tool sits in an environment this PointillViz is not running in. Remove deletes it.

Uninstall

Open the tool and press Uninstall at the foot of its panel, then confirm. The tool and its environment are deleted.

Without internet

The store list reads The store can't be reached; installed tools keep working. ↻ tries again.
