Collect what you want to keep

  1. Press C to keep the view on screen.

    It joins the export folder with its colour key and scale bar.

  2. Press + beside a gene, a selection, a plot or a tool’s result.

    It keeps the numbers as well: a value for each cell, or the plot’s table.

  3. Type a title, or press Enter.

    The folder opens on each item added with +; Esc returns to the viewer.

Look through the folder

Press the folder button in the toolbar, or S.

Drag an item

The file keeps this order. Click a title to rename it.

Compare with…

Compares a kept selection with another one, or with the cells selected on screen.

Figure of 2, 3…

Ctrl- or ⌘-click views in the list, then press it: the views become one figure in the folder.

New folder

One folder makes one file. An item’s ⋯ menu moves it to another folder.

Design

Lays the folder’s pictures out as a figure: see Design Figures.

Change an item

  1. Select the item and press Open.

    The viewer returns to the moment it was taken, and the rest of the app greys out.

  2. Change it where it is drawn.

  3. Press Save changes, Save as new or Discard.

    The viewer then shows what it showed before, and the folder opens again.

Save the AnnData file

  1. Choose the cells in Cells.

    All cells, the cells Visible now, or those of a selection in the folder.

  2. Check the file in AnnData file.

    A line joins each item to the columns, tables and pictures it adds. Untick a column to leave it out; click a pv_ name to rename it.

  3. Keep or untick Expression matrix.

    Without it, the file holds no X or layers and is much smaller.

  4. Press Save .h5ad.

    The files go to the exports folder inside the dataset’s folder; the footer names them.
