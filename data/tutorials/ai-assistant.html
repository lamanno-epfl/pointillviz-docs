The Assistant is a coding agent inside the viewer. A question typed in plain language is answered by an AI runtime, which writes and runs its own analysis on the open dataset, on the computer that serves PointillViz, and publishes figures, tables and notes into a numbered notebook beside the tissue.

The advantage of having the Assistant directly inside PointillViz is that the current analysis does not need to be described first. It can see what the viewer shows, read the cells in a lasso selection, use the same statistics as the tabs and run tools from the Tools tab. It can also publish interactive figures whose elements highlight the corresponding cells in the tissue and, when permitted, control the viewer itself.

Three runtimes are supported, and the notebook uses the one chosen in the panel:

Needs one AI runtime

The Assistant uses an AI runtime installed apart from PointillViz and signed in with your own account; no API key is involved. How to install Claude Code, ChatGPT Codex or Antigravity is described under Installation, Choose a runtime for the Assistant.

Use the Assistant

Choose a part; the page shows only that part.

Start the Assistant

The Assistant is on every page, before and after a dataset is opened. Signing in is needed once and works the same for every runtime. The pictures show Claude Code.

  1. Open the Assistant

    Press Assistant at the bottom right of any page, or Cmd/Ctrl + J.

  2. Sign in

    The first time, the panel shows a card, Sign in once, for the runtime in use. Press its button, Sign in to followed by the name of the runtime.

    If the card says One package missing, that runtime is not installed yet; see Installation.

  3. Finish in the browser

    The browser opens the runtime’s sign-in page. Finish there; the card goes away by itself. On a remote machine, or if the page asks for a code, run the terminal command shown on the card and press Retry. Google Antigravity cannot report whether it is signed in; press I’m signed in when done.

  4. Change the runtime or model (optional)

    Press the pill at the bottom left of the field. It is labelled with the runtime in use, for example Claude Code. Agent settings opens above it.

    Press Runtime, Model or Thinking effort and pick an entry from the list. Runtime offers Claude Code, ChatGPT Codex and Google Antigravity. Model lists the models of that runtime; Runtime default leaves the choice to it. Thinking effort sets how much the model thinks before it answers.

    The three settings are fixed once the notebook has its first question. Press + at the top of the panel to start a new notebook with other settings.

  5. Ask

    Click the field, type a question and press Enter.

Account and data

Once signed in, the panel names the account, for example email · plan · subscription. Questions are answered by that account and count against its plan, or against the API key if one is used. PointillViz does not show cost or token counts; the provider’s account does.

The dataset files stay on the computer that serves PointillViz. What goes to the provider is the question, a short description of the view and of the selection, anything the agent reads or prints while it works, and any picture of the view.

What it sees and can do

This is why the Assistant sits inside the viewer rather than in a separate chat window. The agent knows all of this in every notebook; only Viewer control has to be switched on.

It sees the view

Each message carries a short description of what the viewer shows: the open dataset, 2D or 3D, the zoom, the active tab, what the cells are coloured by, and, when the Genes tab colours them, the gene. Hidden sections and open panels are named too. “Which cell types express the gene I am looking at?” works without naming the gene. The description is taken when the message is sent and renewed after each change the agent makes to the viewer.

It reads the selection

A lasso or slab selection travels with the message it exists for, so “the cells I selected” means exactly those cells. A selection cleared before the next message is not carried over. The agent can compare them with the rest of the tissue or with the same cell type elsewhere. Drawing regions is described under 2D data, Lasso.

The first of the Examples asks about a selection from start to finish.

Interactive figures: hover to highlight cells

Heatmaps, dot plots, bar charts, volcano plots and cell maps are drawn by the viewer, not pasted as pictures. Resting the pointer on a bar or a heatmap cell highlights those cells in the tissue, clicking pins them, and a gene in a volcano plot paints that gene. See Read the results under Work in the notebook.

The agent can also take a picture of the view itself, for instance to check a change it made; each one appears as a VIEW line in the entry’s Method. A picture you take yourself goes with the @ disc, see Ask.

It can drive the viewer

With Viewer control on Ask or Allow, the agent can move the camera, focus on a cell type or region, switch tabs, paint a gene or its own per-cell values, show or hide sections and select cells. See Let it drive the viewer under Work in the notebook.

The third of the Examples shows it: the agent paints a tool’s result and moves the camera to where it found something.

It answers with precomputed results

Differential expression and the ranking of spatial patterns use the code of the Compare and Spatial Patterns tabs, and the neighbour counts of a cell type are the Colocalization tab’s numbers. Results already computed in a tab can be looked up instead of recomputed, so the numbers in the notebook agree with those on screen.

Every tool installed from the Tool Store is known to the agent with its parameters, and it prefers a validated tool over writing the same method again. A tool can run on the whole dataset, on one section or on the selection.

It writes its own analysis

When no tab or tool answers the question, the agent writes a Python script and runs it. It can look at the figure it made and correct it. When the agent attaches the script to a result, it is shown under Derivation.

The second of the Examples asks for something no tab computes.

Work in the notebook

The panel is one notebook: every question is an entry, numbered in the left margin, and everything the agent publishes for it stays with it.

Ask

The composer is the field at the bottom of the panel, Ask about the data — it writes and runs its own analysis. Above it, the orb says what the session is doing: Ready, Running, Awaiting approval or Stopped, with the name of the open dataset.

Type and run

Send a question. Type it and press Enter, or the ↑ button; Shift + Enter adds a line. Questions can be long and can name cell types, genes and sections as they are labelled in the dataset.

Stop. While the agent works, the ↑ button becomes a stop button, and no second message can be sent. To change direction, press stop, then ask again; the interrupted entry stays in the notebook, marked interrupted.

Ask again. Re-run under an entry puts its question back into the composer, to edit or send once more.

Attach the view

Press the @ disc before sending to attach a screenshot of the current view to the next message only. The agent can then answer questions about a pattern it would otherwise only know by numbers, such as “what is the dark band in the middle?”. The picture reaches Claude Code and ChatGPT Codex; Antigravity does not take images.

Auto or Ask

The Auto pill beside the composer decides whether the agent’s commands run without asking.

Auto, the default: commands run without asking. Reading commands always run.

Ask: a command that changes something waits for approval. A bar appears above the composer with Approval needed, the command, and the buttons Allow and Deny, with a five-minute countdown after which the request is denied. The same bar asks for changes to the viewer, see Let it drive the viewer.

Writing files outside the agent’s own working folder and fetching web pages always ask, in both settings.

The agent is code it writes itself

Its scripts run on the computer that serves PointillViz with the permissions of whoever started it, in a working folder of their own under runs/ in the PointillViz folder, with the PointillViz code and the datasets readable. In Auto, installing packages or reaching the internet are ordinary commands and run without asking. Set the pill to Ask to approve each command on a shared or sensitive machine. ChatGPT Codex adds a read-only sandbox of its own.

Read the results

An entry is one question with everything that answered it. What the agent chose to publish is numbered; the working is folded away.

One entry per question

Each entry shows its number and a status icon: a tick, or a different mark if it was interrupted or failed. It contains the question as typed, a folded Method section, the agent’s explanation and its results.

Click Method to see every tool call, thinking block and approval. It opens automatically only when the agent stops to request approval.

Results R01, R02 …

Each published result has a handle such as R01, a title and a type: FIGURE, INTERACTIVE, TABLE, METRICS or NOTE. A line below names the source dataset and number of cells. Open Derivation to see the script that produced the result.

Click a table column to sort it. Metrics appear as a row of tiles.

Find your way

Trace and Readouts at the top switch between the complete notebook and results only. A dot on Readouts marks a result that arrived while Trace was open.

Select ⤢ in a result’s header to fill the panel with it; ← returns to the notebook. N results in the header lists all results, newest first; select one to scroll directly to it.

Linked figures and cell maps

An INTERACTIVE result shows Linked to Cell View when its dataset is open in the viewer. Hover over a bar, heatmap cell, point or legend entry to highlight its cells in the tissue. Click to pin the highlight and click again to release it; Clear highlight removes the pin. Clicking a point that represents a gene paints that gene in the Genes tab.

Use Ctrl/Cmd and scroll to zoom into a chart. Drag to pan and select Reset zoom to return to the original view.

A 2D or 3D cell map adds Colour by for switching between the layers provided by the agent, Fit, and Paint in Cell View, which colours the tissue with the active map layer; the button then becomes Restore Cell View colours. The third of the Examples shows one. If another dataset is open, the chip reads Not linked and tells you which dataset to open.

Let it drive the viewer

By default the agent can only look. Viewer control in the strip under the panel title decides whether it may also change the view.

Off, Ask, Allow

Off, the default: the agent cannot change the viewer and is told so.

Ask: every camera move, tab switch, painting or selection change waits in the approval bar, with Allow and Deny, the same bar as for commands (see Ask).

Allow: the agent changes the viewer without asking; the panel shows an amber outline while it is on.

The setting belongs to the notebook: a new one starts at Off again. Google Antigravity has no way to show an approval, so Ask is refused there; use Allow or Off.

What it may change

The agent can control:

  • Camera: pan, zoom, rotate, fit, or focus on a cell type, section or selection
  • Active tab
  • Colouring: cell type, gene, gene density, up to three genes, any categorical or continuous column, or its own per-cell values with a colour key
  • Visible sections
  • Selection: explicit cells, polygon, rectangle or 3D box
It cannot move panels or open dialogs.

Each change appears as a VIEW row in the entry’s Method, marked applied or failed. It is refused if another dataset has opened since it was requested.

Keep or restart

The notebook is kept on the computer that serves PointillViz, in the session’s own folder, not with the dataset. The export is the copy to keep.

Export

The download button in the header writes the whole notebook as one web page, with every figure and script inside it and every drawer opened; the browser’s print command turns it into a PDF. Interactive figures become a note saying they are only available inside PointillViz; clickable matplotlib figures keep their picture. Copy under an entry copies that entry alone, as Markdown.

Reopen

After reloading the page, the panel restores the most recent notebook. If its session is still active, it continues as before.

A session ends after six hours without a question or when PointillViz is restarted. The notebook then reopens from its record, with the note Reopened notebook. Your next question continues it: the next question starts a session on the same record, with Viewer control back at Off. Earlier approvals show their verdicts and are not asked again.

Only the most recent notebook is restored, so export any others you want to keep.

New

The + button starts a new notebook on the runtime, model and effort currently chosen, with Viewer control back at Off. When the current notebook has entries, a confirmation asks first; they are cleared, so export before pressing it. Switching datasets does not need a new notebook: the open dataset is sent with every question.

Examples

Three real questions, asked with Claude Code on a Xenium section of the mouse maternal–fetal interface at day 16.5. The answers are the agent’s output and vary from run to run; Method and Derivation show what was run. Choose one.

Compare cells inside a region

Draw a region with the Lasso (see 2D data, Lasso), open the Assistant and ask about it:

Inside my selection, which genes are higher in the NK cells (MD (NK cells)) than in the NK cells elsewhere in the tissue? Show a volcano plot linked to the tissue and name the five strongest.

The agent runs the test of the Compare tab on the NK cells inside the region against those outside it and publishes a volcano plot. Clicking a point paints that gene in the Cell View.

Measure what no tab measures

No tab computes the distance from one tissue compartment to every other cell. The agent writes the script for it. To let it paint the result, set Viewer control to Ask or Allow first (see Let it drive the viewer under Work in the notebook); with Ask, each change to the viewer waits for your Allow.

For every cell, compute the distance to the nearest Labyrinth cell. How far do the invasive trophoblasts (MD (Invasive GlyT)) reach into the maternal side compared with the other maternal cell types? Show it as a chart, and paint the distance on the tissue.

The agent decides which cells count as the labyrinth and names its reference above the chart. It publishes a box plot of the distances per cell type, junctional-zone types on the left and maternal types on the right, and paints each cell’s distance on the tissue.

Run a tool and go there

A tool from the Tool Store runs on the whole dataset, and with Viewer control the agent can show where it found something. With Expression Hotspots installed and Viewer control set to Ask, ask:

Run the Expression Hotspots tool for Prl8a2, paint the hotspot score on the tissue, and zoom the viewer tightly onto the strongest hotspot patch.

The agent starts the installed tool, which scores every cell for Prl8a2 as a Getis-Ord Gi* hotspot. Before changing the viewer, Claude asks for permission twice: first to paint the score on the tissue, then to move the camera to the strongest patch. Each Allow authorizes Claude to perform the change itself; the user does not need to adjust the viewer manually. After the second Allow, the patch is shown, and the minimap marks its position in the section.

The notebook keeps more than the map. The agent published a table of the patches and a note with its caveats, and its answer says what it could not do and offers two tighter frames. The steps are in Method.
